# Fuente bíblica integrada

Biblia Clara IA incluye **La Biblia en Español Sencillo** (identificador `SPNBES`) para proporcionar los 66 libros con texto local.

> La Biblia en Español Sencillo © 2018, 2019 AudioBiblia.org / Irma Flores. Traducido y editado por Irma Flores. Publicada bajo la licencia Creative Commons Reconocimiento 4.0 Internacional.

La aplicación debe mostrar la atribución anterior y el enlace a la licencia `https://creativecommons.org/licenses/by/4.0/`. El texto se integra sin modificar; si en el futuro se adapta, debe declararse de forma visible que se hicieron cambios y que el licenciante original no los respalda necesariamente.

| Elemento           | Valor                                                                 |
| ------------------ | --------------------------------------------------------------------- |
| Traducción         | La Biblia en Español Sencillo                                         |
| Idioma y variante  | Español; América Latina/México                                        |
| Fuente técnica     | Archivo USFX `spa-bes.usfx.xml` del repositorio `seven1m/open-bibles` |
| Licencia           | Creative Commons Attribution 4.0 International (CC BY 4.0)            |
| Titular acreditado | AudioBiblia.org / Irma Flores                                         |
| Uso en la app      | Texto local de los 66 libros y versículos; sin solicitudes remotas    |
